# phaseR
A new and updated software suite for the analysis and visualization of circadian and ultradian rhythms in Drosophila activity and sleep. Merges important and useful functions from RhythmicAlly and PHASE.

Research on circadian rhythms often requires researchers to estimate period, robustness and phase of the rhythm. These are important to estimate owing to the fact that they act as readouts of different features of the underlying clock. The commonly used tools, to this end, suffer from either being very expensive or have very limited interactivity or are very cumbersome to use, or a combination of these. To overcome these issues and to ease the analysis of biological time-series data, we have updated RhythmicAlly, an open source program using R and Shiny and have merged important functionalities from RhythmicAlly and PHASE and added new functions to create this new analysis software powerhouse - phaseR.

Last update on 20th June 2025.
