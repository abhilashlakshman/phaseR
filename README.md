# phaseR
A new and updated software suite for the analysis and visualization of circadian and ultradian rhythms in Drosophila activity and sleep. Merges important and useful functions from [RhythmicAlly](https://github.com/abhilashlakshman/RhythmicAlly) and [PHASE](https://github.com/ajlopatkin/PHASE).

Research on circadian rhythms often requires researchers to estimate period, robustness and phase of the rhythm. These are important to estimate owing to the fact that they act as readouts of different features of the underlying clock. The commonly used tools, to this end, suffer from either being very expensive or have very limited interactivity or are very cumbersome to use, or a combination of these. To overcome these issues and to ease the analysis of biological time-series data, we have updated RhythmicAlly, an open source program using R and Shiny and have merged important functionalities from RhythmicAlly and PHASE and added new functions to create this new analysis software powerhouse - phaseR.

Last update on 20th June 2025.

Run all the codes in install.R. This is required to be done only once and for the first time before running phaseR. Next, set your working directory to the folder which contains the phaseR files. Then users may type in "shiny::runApp()" on the RStudio console to initialize and start using phaseR.

Please see the following manuscript for an example of the new functions included in phaseR:
[Abhilash et al., 2026](https://www.cell.com/current-biology/fulltext/S0960-9822(26)00015-1).

Please READ the [manual](https://github.com/abhilashlakshman/phaseR/blob/main/phaseR_UserManual_v01.html) before using.
